# AquaChord — เว็บแอป (static PWA + หลังบ้าน PHP/MySQL)

โปรโตไทป์ที่ใช้งานจริงบน **https://aquachord.online** — ฝั่งหน้าเว็บเป็น static ล้วน (ไม่มี build step) ฝั่งหลังบ้านเป็น PHP 8.3 + MySQL/MariaDB
(พิมพ์เขียว/สถาปัตยกรรมฉบับเต็มอยู่ที่ [`../docs/`](../docs/))

## โครงสร้าง
```
site/
├── index.html · assets/ · manifest.webmanifest · sw.js   ← PWA แอปหลัก
│   └── assets/js: i18n · music (Web Audio + ท่าจับทุกคอร์ด) · chordpro · store
│                  · dsp (เอนจินคอร์ด + แยกเสียงร้อง — เทสต์ใน ../tools/test-dsp.cjs)
│                  · lyricfix (ใส่เนื้อร้องที่ถูกต้อง → จัดให้ตรงจังหวะ/คอร์ด — test-lyricfix.cjs)
│                  · lyrics + lyrics-worker (Whisper ในเบราว์เซอร์) · analyze
│                  · riff (แกะทำนอง/โซโล่ → แท็บกีตาร์ — เทสต์ใน ../tools/test-riff.cjs)
│                  · stems + stems-worker + tracks (แกะทุกเครื่องดนตรีเป็นแทร็กโน้ต: CPU = HPSS + Basic Pitch ·
│                    GPU = HT-Demucs 6 stem + Basic Pitch บน WebGPU — เทสต์ ../tools/test-tracks.cjs, e2e ../tools/e2e-tracks.mjs)
│                  · trackstore (IndexedDB) · mixer (เล่นหลายแทร็ก M/S/vol) · midi (ส่งออก .mid + ไฟล์ DAW/FL Studio — test-midi.cjs)
│                  · polish (เกลาโน้ตตามหลักดนตรี: ต่อโน้ตขาด/แก้อ็อกเทฟ/ลากเสียง/เติมคอร์ด — test-polish.cjs)
│                  · notation (โน้ตสากล/โน้ตไทยด้วย abcjs — test-notation.cjs) · finger (เรียบเรียงฟิงเกอร์สไตล์ — test-finger.cjs)
│                  · practice (ฟังกีตาร์ผ่านไมค์ ตัดสินโน้ต/คอร์ด/จังหวะ — test-practice.cjs) · tracksui (UI ทั้งหมดของส่วนนี้)
│                  · fx (ฉากหลัง + กีตาร์น้ำ 3D WebGL) · guide (ไกด์อควา) · app (shell/router/หน้าต่าง ๆ)
│   └── assets/guide/ : face-160.webp + clips/*.webm (คลิปไกด์ VP9 โปร่งใส — ไม่มีไฟล์ก็ใช้ภาพนิ่งแทน)
│   └── assets/brand/ : โลโก้ WebP ขนาดเล็ก (logo.png/logo-mark.png ตัวใหญ่ยังอยู่ให้หลังบ้านใช้)
├── api/            ← REST API (PHP): index.php + lib/(util,db,auth)
│   └── config.sample.php   ← คัดลอกเป็น ../private/config.php (ใส่รหัส DB จริง)
└── admin/          ← หน้าหลังบ้าน (SPA): index.html · admin.css · admin.js
```

## ฟีเจอร์หน้าเว็บ
หน้าตาแบบ "hub" (ภาษาภาพเดียวกับ XMAN GAMES HUB): sidebar ซ้ายบนจอใหญ่ · แถบแท็บล่างบนมือถือ/แท็บเล็ต · หัวข้อ 3D · spotlight panel · กีตาร์น้ำ 3D (ray-marched WebGL, ลากหมุนได้ สายสั่นตอนดีด) · ปุ่ม Motion พักแอนิเมชัน · ธีมมืดนีออนน้ำ
- **แกะเพลง** — **แกะคอร์ดจากไฟล์เสียงจริงในเครื่อง 100%** (DSP: ชดเชยจูนเพี้ยน · แยกเบสช่วยหา root · คอร์ด maj/min/7/m7/maj7 · Viterbi รู้คีย์ 2 รอบ) · **ถอดเนื้อร้องไทย/อังกฤษด้วย Whisper ในเบราว์เซอร์ (Beta)** โดยแยกเสียงร้องออกจากดนตรีก่อน · ตรวจว่ามีเสียงร้องจริงก่อนถอด (Silero VAD) เพลงบรรเลงข้ามได้ในไม่กี่วินาที · กัน Whisper วนซ้ำ/หลอน + จำกัดเวลา (test-lyrics-guard.cjs) · งานแกะวิ่งเบื้องหลังได้ (เปิดหน้าอื่นระหว่างรอ มีตัวบอก % บนแถบบน) · ยกเลิกต้องยืนยัน
- **คลังเพลง** — ค้นหา (กด `/`) · กรองโปรด/มีเนื้อร้อง · เรียง 4 แบบ · ลบแบบยืนยัน + เลิกทำได้ · นำเข้า/เขียนเอง
- **หน้าเพลงแบบแท็บ** — แถบเมนูด้านบน (แผ่นคอร์ด · เล่นตามเพลง · แท็บโซโล่ · แทร็ก/MIDI · ฟิงเกอร์สไตล์) เปิดทีละหน้า ไม่ต้องเลื่อนยาว จำแท็บต่อเพลง · แถบควบคุมลอยตามจอ (เล่น/หยุด คีย์ คาโป้ BPM ขนาดอักษร) · **เล่นได้ทีละตัว** กดเล่นอันใหม่ = หยุดอันเก่า หยุดแล้วเงียบทันที (`Music.transport`)
- **แผ่นคอร์ด** — เปลี่ยนคีย์ · **คาโป้เปลี่ยนท่าจับให้จริง** (เสียงที่ได้ยินยังตรงคีย์) · ขนาดตัวอักษร (จำค่า) · เลื่อนอัตโนมัติ 5 ระดับ + กันจอดับ (Wake Lock) · แถบท่าจับทุกคอร์ดในเพลง · ฟังทางเดินคอร์ดตามจังหวะจริงจาก timeline · ดาวน์โหลด .cho · คีย์/คาโป้จำแยกต่อเพลง
- **เล่นตามเพลง** — จังหวะการตี 10 สไตล์ (ป๊อป บัลลาดเกา สโลว์ร็อก ร็อก ลูกทุ่ง/รำวง เร็กเก้ บอสซา แทรวิส วอลทซ์ …) แสดงลูกศร/นิ้วพร้อมไฮไลต์ · ลูกเล่นโซโล่ (เบนด์/สไลด์/ไวเบรโต) · ปรับ BPM · **เลือกเสียงกีตาร์หรือเปียโน** (เปียโนแสดงคีย์เปียโนแทนท่าจับ)
- **แท็บโซโล่/ริฟฟ์ (Beta)** — แกะทำนองเด่นจากไฟล์เสียงเป็นแท็บกีตาร์ในเครื่อง (จัดสาย/เฟร็ตให้มือขยับน้อย) · เล่นแท็บ 0.5×–1× · คัดลอก/ดาวน์โหลด .txt · เก็บแยกที่ `aq.riff.<id>` ไม่แตะ SongDoc
- **ใส่เนื้อร้องที่ถูกต้อง** — วางเนื้อเพลงจริง (ตอนแกะเพลง หรือในหน้าเพลงที่แกะแล้ว) → `lyricfix.js` เทียบทีละตัวอักษรกับคำที่ Whisper ถอดได้ (ไม่สนวรรณยุกต์/พยัญชนะเสียงเดียวกัน) แล้วใช้เนื้อของผู้ใช้แทน โดยคงจังหวะจริงและคอร์ดบนพยางค์เดิม · ใส่ท่อนฮุกที่ร้องซ้ำให้เอง (เนื้อเขียน "(ซ้ำ *)" ก็ได้) · ตัดป้ายท่อนให้ · เลือกภาษา Whisper ตามเนื้อที่วาง · ถ้าเนื้อไม่ตรงกับที่ถอดไว้ (เช่นถอดผิดภาษา) ให้ AI ฟังไฟล์เดิมใหม่โดยใช้เนื้อนำทาง · เลิกทำได้ (เทสต์ `../tools/test-lyricfix.cjs`)
- **แทร็กเครื่องดนตรี / MIDI (Beta)** — แกะไลน์กลอง เบส ทำนอง คอร์ด (+ กีตาร์ เปียโน เสียงร้อง ในโหมด GPU) เป็นโน้ตจริง มีจังหวะเข้า-ออก-พักตามเพลง · เปิดได้ตอนแกะเพลงหรือแกะเพิ่มให้เพลงเดิม · 2 โหมด: **พื้นฐาน (CPU ทุกเครื่อง ~3 MB)** และ **AI แยกเครื่องดนตรี (WebGPU, โมเดล ~277 MB ครั้งแรก, แม่นกว่า + แกะคอร์ดจากเสียงที่ตัดกลอง/เสียงร้องออก + ถอดเนื้อจาก stem เสียงร้อง และข้ามการถอดเนื้อเมื่อไม่มีเสียงร้อง)** · เล่นพร้อมกันทุกแทร็ก เลือก Mute/Solo/ระดับเสียง/ความเร็ว · piano roll · ดูเป็นโน้ตสากล/โน้ตไทย/แท็บ (กีตาร์ 6 สาย, เบส 4 สาย)/ตารางกลอง · **เกลาโน้ตด้วย AI ตามหลักดนตรี** (ต่อโน้ตที่ขาดเป็นท่อน แก้อ็อกเทฟที่เพี้ยน ลากเสียงให้ยาวพอ ตัดโน้ตหลง เติมเสียงคอร์ดที่หาย — เปิด/ปิดได้ โน้ตที่เติมแสดงเส้นประ) · **ส่งออก .mid** · **ส่งออกไป FL Studio** (MIDI หลายแทร็กตรงห้อง + แทร็กคอร์ด/ฟิงเกอร์สไตล์/โซโล่ + marker ชื่อคอร์ด) · เก็บใน IndexedDB แยกจาก SongDoc (ลบเพลง = ลบแทร็ก, เลิกทำได้)
- **ฟิงเกอร์สไตล์** — รวมทำนอง+เบส+คอร์ด เป็นแท็บกีตาร์ตัวเดียว 4 สไตล์ (ทำนอง+เบส · แทรวิส · อาร์เปจโจ · คอร์ดเมโลดี้) × ง่าย/ปกติ · เลือกคาโป้อัตโนมัติ · ตรวจกฎเล่นได้จริง (สายละโน้ต, ช่วงเฟร็ต ≤4–5, ย้ายมือไม่กระโดด) · เล่นฟังแบบปล่อยสายกังวาน (let ring) · ส่งออก .mid/.txt
- **ฝึกผ่านไมค์ (Beta)** — ฟังกีตาร์ของผู้เล่นในเครื่อง (ไม่อัด ไม่อัปโหลด) ตัดสินโน้ต/คอร์ด/จังหวะ · โหมดรอจนเล่นถูก หรือ ตามจังหวะ + ดนตรีประกอบ (ตัดแทร็กที่ฝึกออก ควรใส่หูฟัง) · วัดความหน่วงไมค์ · ใช้ได้กับแทร็ก, แท็บฟิงเกอร์สไตล์ และคอร์ดทั้งเพลง
- **ตรวจ GPU ของเครื่อง** — ถ้ามี WebGPU ถอดเนื้อร้องด้วย GPU และเปิดโมเดล Whisper large-v3-turbo (แม่นสุดสำหรับเพลงไทย) · ไม่มี GPU → CPU + แจ้งผู้ใช้
- **ห้องคอร์ด** — ท่าจับกีตาร์ทุกคอร์ด (เปิด + ทาบ E/A-shape ทุก root) เสียงตามท่าจับจริง · คอร์ดในคีย์เมเจอร์/ไมเนอร์ · ทางเดินคอร์ดยอดนิยม
- **แก้ไขเพลง** — ChordPro + พรีวิวสด · แตะชิปคอร์ดเพื่อแทรกตรงเคอร์เซอร์ (มือถือไม่ต้องพิมพ์ `[ ]`) · กันออกโดยไม่บันทึก
- **ไกด์อควา** — มาสคอตแนะนำแบบ Nova: ยืนบนพาเนลบนจอ ≥1280px, รูปหน้าในวงกลมบนจอเล็ก, พิมพ์ข้อความทีละตัว, จิ้มแล้วมีปฏิกิริยา, พาทัวร์ 5 ขั้น · คลิปขยับใช้ VP9 alpha (Safari/iOS/ประหยัดเน็ต/ปิด Motion → ภาพนิ่ง)
- สองภาษา ไทย/อังกฤษ · ติดตั้งเป็นแอป (PWA) ใช้ออฟไลน์ได้ · สำรอง/นำเข้า/ล้างคลังในหน้าตั้งค่า

## หลังบ้าน (`api/` + `admin/`)
- **ล็อกอินครั้งแรกสร้างแอดมิน** (owner) — ป้องกันสร้างซ้ำ, bearer token, จำกัดล็อกอินผิดต่อ IP
- จัดการสารบัญเพลง (เพิ่ม/แก้/ลบ/เผยแพร่) · ผู้ดูแลหลายคน · ตั้งค่าเว็บ · สถิติ
- endpoint สาธารณะ `/api/catalog`, `/api/site` สำหรับหน้าเว็บดึงไปใช้
- ความปลอดภัย: `password_hash`, PDO prepared statements, `no-store`, รหัส DB อยู่นอก webroot

## ติดตั้งหลังบ้าน (สรุป)
1. สร้าง MySQL database + user (**charset utf8mb4** สำคัญ ไม่งั้นภาษาไทยเพี้ยน)
2. คัดลอก `api/config.sample.php` → `<โดเมน>/private/config.php` (นอก webroot) ใส่ค่าจริง + `chmod 600`
3. ตาราง migrate อัตโนมัติเมื่อเรียก API ครั้งแรก
4. เปิด `/admin/` → สร้างบัญชีผู้ดูแลคนแรก

## Deploy
เป็น static + PHP → ก๊อปไฟล์ใน `site/` ไปที่ `public_html` ได้เลย (ต้องเป็น HTTPS สำหรับ PWA/Service Worker)
บัมป์ `VERSION`/`CACHE` ใน `sw.js` ทุกครั้งที่แก้ asset เพื่อให้เครื่องผู้ใช้โหลดของใหม่

> ⚠️ ห้าม commit `config.php` หรือไฟล์ `.sqlite` — กันไว้ใน `.gitignore` แล้ว
